# 09体检区 GCN 房间布局复原试验计划

**目标：**在用户已选择的“给定房间清单和连接，预测房间位置与大小”条件下，完成单图小片区训练、基线对比和可视核查。

**实现：**仅使用已有 NumPy、Pillow 和 Python 标准库。采用两层对称归一化 GCN 加逐节点四维输出，预测归一化中心、宽、高。此次为同图拟合诊断，没有验证集、测试集或跨医院泛化结论。

**约束：**不安装依赖；不改原图及原标注；每个代码文件至多599行。输入不含坐标、面积、门位、空间序号、含方位的名称或唯一身份嵌入。关系为给定的概念 access，不宣称全部是直接门连接。未列关系不当作建筑不连通的负例。

**代码位置：**`m-GCN模型/room_layout_pilot/`。

**结果位置：**`e-实验评估/20261103_09体检区_GCN复原/`。

- [x] 先写并运行数据泄漏、归一化、置换等变性及梯度数值校验测试，确认实现缺失时失败。
