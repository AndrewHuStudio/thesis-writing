# 门诊平面资料：GCN适用性初评

评估日期：2026-10-25。

评估范围：`i-医院门诊平面/`内现有17张JPG，按文件名暂分为10个项目组。医院主体、院区、楼栋与年代尚未通过原始出处逐项核实，10个项目组不等于已经确认的10个独立医院样本。本次逐张查看整图，并对部分细节放大、对横置图制作临时旋转副本；没有移动、改名或覆盖原图，没有生成训练标签或运行GCN。

## 总体判断

这些资料有助于建立节点分类、关系标注和图数据处理流程，但目前仍是候选原始资料，不是已经验收的训练数据。17张图中既有门诊诊区，也有公共服务、急诊、医技、住院及手术功能。普通门诊主训练集需要先按功能范围筛选，不能按文件夹名称全部纳入。

目前可明确排除整层纳入普通门诊主训练集的有3张：佛山市禅城区中心医院六层、广东省人民医院五层、济南大学附属医院五层。其他14张分别具有诊区、公共服务、医技或专科补充价值；不能将其直接表述为14个已合格训练样本。

以下是图面初评，不是逐房间与逐关系验收；“优先试标”仍要求补齐来源、功能类别和证据。“可见门洞”不等于所有门洞均已辨认，更不证明访问权限与交通网络完整。

## 这批资料对训练的实际帮助

1. **可启动标注与流程原型。**先用功能图例清楚的北京大学门诊楼二层建立节点和关系规则，再用另一家医院的门诊诊区检查规则是否适用。长海文件的楼层矛盾应先解决。
2. **支持不同层级的信息采集。**对有房间名称的图保留细粒度事实；对只有功能区标识的图，仅标已知功能区。两种粒度分别建立图样本，不直接混成同一种节点。
3. **有助于发现类型偏差。**17张中10张文件名为一层；其中多张偏向大厅、药房、急诊或影像。后续应重点补充其他医院普通门诊诊区层，而不是继续只增加入口层。
4. **不能据此保证泛化性能。**目前的项目组数量和有效图数量均有限，且尚无标注覆盖率、类别分布、医院分组后的实验结果。可以试验模型，但还不能作“样本量足够”或“跨院预测有效”的结论。

## 入库前需要补齐

- 来源：书名/网页、作者或供稿单位、出版信息、页码/图号、取得日期及使用说明。当前图像目录未见来源台账，来源可能保存在别处，需建立对应关系。
- 身份与版本：医院全称、历史别名、院区、楼栋、楼层、设计阶段及年份。“2014年以后”不能从当前这些裁图一概确认；出版年份不代替设计/建成年份。
- 范围：全层或局部、普通门诊/急诊/医技/住院/专科类型、裁切边界及外接交通接口。
- 节点：已核实功能、空间边界、上级科室；不明确的功能记录未知，不凭图形猜测。
- 关系：共墙、直接开门、经交通空间可达分别标注；每项都有已知/未知状态。共墙不自动意味着直接通行，设计流线箭头不直接等于门洞证据。
- 几何：尺度来源与变换。轴网和图示比例尺可用于校准，但需验证扫描变形；开放大厅/候诊区的分界必须另定规则，色块接触不自动当作共墙。
- 分组：同医院的不同楼层、局部裁图、处理副本和同源版本不得跨训练、验证与测试集。文件哈希不同仅排除字节级完全重复，不排除同源与近重复。

## 形成图数据时的任务边界

对于“给定功能任务书预测空间关系”的主线，图片经人工核验后形成节点属性与关系标签。真实图纸上的质心、实际邻接、门洞位置等可作为标注/评价信息；若新设计任务中尚不可获得，不应直接作为预测输入。相同功能诊室的实例编号也不能暗带其真实空间顺序。

建议第一步先制作两个项目的试标样本，并记录可确认功能、共墙、门洞的覆盖情况及耗时；再决定继续采用房间级，还是另建功能单元级实验。局部裁切是数据组织方式，不会自动增加独立医院数量。
