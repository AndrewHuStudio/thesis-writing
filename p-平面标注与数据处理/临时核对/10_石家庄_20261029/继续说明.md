# 10号草稿续作说明

当前正式样本目录仅四文件，核心JSON为事实来源。核对编号映射.json 记录本轮固定 01—135 与 S 编号的对应，分批确认时不重新编号；用户的已确认名称必须保留。

build_draft.py 仅为首次建稿脚本。收到任何确认后不得直接重跑它，以免覆盖用户确认。后续应读取现有 annotation.json，只更新相应名称、类别、范围或关系，再按 Skill normalize → render → summary → validate --check-dir。说明中保留范围和精度信息。

make_review.py 为本轮完整核对图生成脚本，目前按135项未知编排；分批确认后的核对图须沿用本轮映射而不是重新连续编号。候选仅在核对材料，核心 unknown 在用户确认前不得改为候选名称。

09、20、69、81、110、111 为6处大型庭院，需要确认室内可步入还是露天／挑空；124为弧形入口范围。全部未确认区域暂参与室内面积，确认露天后按 courtyard/open_space 排除并重新归一化，不补造人员可达关系。
