## 1. 建筑边界：可以提取，采取半自动提取与核验

53张原图都是JPG。各图在已标注范围内可见建筑/目标空间外缘信息；尺寸链、比例尺、室外附属物的完整程度有差别。不是因为核心JSON没有建筑边界字段，就需要重新寻找图纸。

建议顺序：

1. 以当前稳定S号和目标范围定位当前这一层，排除图例、页框、另一层残片、总图道路与无关附图。
2. 通过原图外墙/外缘线、已有空间轮廓和必要的图像轮廓处理，提取目标层外壳。保留多翼/多部件情况。
3. 另行保存庭院、挑空及明确不可布置区域的孔洞/排除轮廓，不用实心大矩形或凸包填平。
4. 将外壳叠加原图核验；统一决定门斗、廊道、雨棚、平台、独立附属单元是否属于模型的可布置域。
5. 形成训练适配文件中的`outer_shells_px`、`exclusion_polygons_px`、`source_scope`和核验状态，原四文件不增加训练过程字段。

本轮已为每图保存两种GeoJSON证据：原室内空间并集，以及采用长边0.1%缓冲半径进行小间隙闭合的候选包络。它们位于`候选轮廓/`，属性明确标为`verified_boundary=false`。闭合参数是审计探针，不是建筑墙厚或边界真值。

从总览可见：部分样本房间轮廓间留有墙厚/描绘间隙，直接并集会产生大量分片；还有分翼、庭院、多图同页等情况。因此不能仅凭并集连成几块，就判断建筑真的断开；也不能扩大缓冲直到全部粘连。这一步需依原图外缘完成。

**尤其不能把带有室内房间碎缝的原始并集当作外边界输入；它可能将室内划分信息带给模型。**

优先关注图面：13号拍摄页的透视与遮挡，16/17/27/48/51号额外图块，03/31/40/45/52号多部件或独立单元，53号庭院及潜在屋面/室内外范围。逐图备注与预览在清单中。

并集、缓冲操作的行为参考：[Shapely并集文档](https://shapely.readthedocs.io/en/stable/reference/shapely.unary_union.html)、[几何操作手册](https://shapely.readthedocs.io/en/stable/manual.html)。这些操作不自动提供建筑语义判断。

## 2. 尺寸：相对布局训练＋用户实际边界还原

第一版采用同一个长度因子归一化x、y、宽度和高度，保持图形长宽比。以**核验后的建筑边界**外接范围为基准：

```text
L = max(xmax - xmin, ymax - ymin)
x_norm = (x - xmin) / L
y_norm = (ymax - y) / L
width_norm = width_px / L
height_norm = height_px / L
area_norm = area_px / L²
```

这将原图左上原点、y向下的坐标转换成局部左下原点、y向上的坐标。x和y不分别缩放到正方形；短边保留实际比例。原有`area_ratio`是室内面积分母下的占比，与`area_norm`的分母不同，不能混用。

用户在Rhino等软件中画出实际尺寸的边界后，在同样的局部平面中求`L_user`，用`width_norm × L_user`等还原，最后转回用户坐标系。新轮廓的形状由模型作为条件接收；不能把某个旧布局做线性拉伸就声称适配了任意新边界。几何模块继续处理贴边、非重叠与必要尺寸要求。

本轮对全体标注顶点验证了归一化和逆变换公式，最大还原误差约4.55e-13像素。审计阶段使用空间包络的临时坐标框仅用于核验公式；正式训练应换成已核验建筑边界定义的坐标框。

核心JSON均未记录米/像素换算，但原图中有尺寸链或图形比例尺。后续有可靠依据时，可以用两端可定位的已知尺寸跨度计算`meters_per_pixel`，保存依据并检查多个跨度是否一致。拍摄变形、非等比例扫描应先校正或标为不具备可靠米制监督。

**相对尺度方案能训练组织与比例；它不会自动补出原图真实平方米。** 对仅边界模式，如果训练时没有真实尺度，单凭归一化形状也无法学出不同实际大小应有多少间房。空间配置推荐需结合用户边界的实际尺寸及另行给定/检索的面积要求；米制数据后续可作为额外监督逐步加入。

43个type编码均在现有共享类别表内；其中包括unknown。scope目前有106种原始写法，不宜未经映射就当作统一跨院功能标签。建议优先用共享type与level，scope原文保存，并另建有依据的归并表。

组合关键词仅用于筛查。例如“挂号／收费”“会议／示教室”可能本来就是同一个物理房间；“男更衣+女更衣”“女卫男卫”可能是组合单元，需看该图。详见[28项组合名称候选](组合名称复核_28项.json)。

### 关系与门洞

关系共10,182条：access 8,589、service 286、shared_wall 797、entrance 510。access中有1,792条没有定位开口，可保留概念通行语义，不伪造门位。未记录关系保持未知；明确不连接的监督只能来自明确证据。

定位开口共7,200个。本轮额外计算“点到关系两端空间多边形的最大距离”：

| 阈值 | 超过阈值的点数 |
| --- | ---: |
| 1像素 | 2,722 |
| 5像素 | 751 |
| 10像素 | 161 |
| 建筑占用包络长边0.5% | 85 |
| 建筑占用包络长边1% | 14 |

阈值用于排序，不是错误判定标准。总览和14个最大相对距离的局部图提示：有墙厚/粗轮廓留白，也有需要进一步核实的端点与分割后关系定位问题。不能将2,722点全判为错误，亦不能据此证明其余点语义全部正确。

本轮生成14项优先复核局部图，见[坐标和预览索引](门洞距离优先复核.json)。其中51号P010和P067共用一个坐标但对应不同空间对，需优先结合拆分记录回看；目前仅记录复核提示，没有删除或改写原关系。

第一版布局训练建议暂不训练精确门位；概念access与精确开门任务分开。距离最高优先级相关关系的监督在候选策略中先屏蔽，回图确认后再恢复；这是一项保守使用策略，不代表已经判定连接不存在。

## 4. 数据划分：遵从本轮全部做训练来源的安排

53图全部保留在训练候选池，不预留、不删除、不随机拆出测试图。保留原图编号、文件哈希和来源，后续新增独立测试资料时可以追溯。

目前的训练结果可用于观察拟合、损失下降、重叠/越界诊断及软件流程。将来需要证明对新医院/新边界有效时，再另做独立评估。本轮没有把训练误差称为泛化效果。

## 建议的执行顺序

1. 逐图提取核验后的单层外壳和明确排除域，训练适配记录另存；保留原空间层。
2. 采用等比例归一化，保存原点、长度因子、坐标方向与逆变换；有尺度依据的图另行校准米制信息。
3. 复核28项组合候选、14项优先门洞定位，并处理scope映射；未知功能保留mask，不要求全补名才开始。
4. 导出53图的训练数据。先做布局位置与尺寸任务，再决定关系预测/配置推荐的具体模型；未指定关系的场景必须明确候选图如何形成。
5. 训练时严格区分输入与答案。如果把原图完整access当输入，该实验只检验“给定关系的布局”，不能作为“仅边界生成”已经实现的证据。

第一轮可比较使用已知房间监督与加入粗/缺功能几何监督的拟合表现；用户暂缓独立测试时，仅报告训练诊断。
