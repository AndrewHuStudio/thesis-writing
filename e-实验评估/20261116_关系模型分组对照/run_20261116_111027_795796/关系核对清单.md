# 空间关系核对清单

从不同规模的5张图中选取30对未参与正负监督的空间关系。每张图包含3对留出预测高分候选，以及3对从其余未参与正负监督空间对中均匀抽取的候选。请按既有access标注口径填写连接、不连接或无法判断，并简述证据。

这批候选用于排查标注缺口和典型错误。高分抽样影响样本分布，后续正式精确率评价需要预先确定覆盖范围与抽样方式。
